## Quick facts

- Windows 10 version 1809+ / Windows 11, x64; the release includes .NET 10.
- English interface; no main application window during normal background operation.
- Default: a 20-minute work interval, a heads-up in its final 30 seconds, then a 20-second rest.
- The application does not make network requests, capture the screen or track your input.
- Linux is currently unsupported. The UI and platform integrations are Windows-specific.
